MIRO-8 — ГОТОВЫЙ САЙТ

1. Распакуйте ZIP.
2. Внутри должны лежать index.html и папка assets.
3. Создайте публичный репозиторий miro8-site в аккаунте mebelm161ru-bot.
4. Загрузите СОДЕРЖИМОЕ распакованной папки в корень репозитория.
5. Не загружайте ZIP как единственный файл — GitHub Pages его не распакует.
6. Settings → Pages → Deploy from a branch → main → /root → Save.

Первый адрес:
https://mebelm161ru-bot.github.io/miro8-site/

Подробная инструкция находится рядом с ZIP в файле:
00_САМАЯ_ПРОСТАЯ_ИНСТРУКЦИЯ_ЗАПУСКА_САЙТА.docx
